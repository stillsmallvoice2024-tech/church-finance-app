## Simple words for every term

Look up any word you meet in the app or in this tutorial.

| Word | Simple meaning |
|---|---|
| Inflow | Money coming IN to the organisation |
| Outflow | Money going OUT of the organisation |
| Transaction | One single money event — one gift, one payment |
| Import | Loading a whole bank statement file into the app |
| Bank statement | The list of transactions your bank gives you |
| Fund | A bucket for money, like "Building Fund" or "Welfare" |
| Fund group | A folder that holds related funds together |
| Portion / Fund Type | A pocket inside a fund: Regular Funds, Designated Gift, or Savings |
| Regular Funds | The pocket filled by percentage splitting of normal income |
| Designated Gift (Specific Seed) | Money given for ONE stated purpose only |
| Savings | Money set aside as a reserve — the rainy-day pocket |
| Distribution rule (Allocation config) | The recipe that splits incoming money between funds |
| Special config | A one-off splitting recipe for a special occasion |
| Locked | Approved and in use; can no longer be edited |
| Draft | Saved but not yet in use |
| Income type | A name tag for money in, like "Tithes" or "Offerings" |
| Outflow type | A name tag for money out, like "Salaries" or "Utilities" |
| Department | A team or unit in the organisation, like "Welfare" or "Music" |
| Ledger | A running list of transactions with the balance after each one |
| Balance Brought Forward (B/F) | The money already there before the list starts |
| Running balance | The balance recalculated after every row |
| Reconciliation | Checking that the app's records match the real bank |
| Reference balance | The closing balance printed on your real bank statement |
| Refund | Real money paid back — cash actually moved |
| Reversal | Cancelling a wrong record — no real cash moved |
| Root / Original | The first transaction in a matched pair |
| Offset | The partner transaction that cancels or adjusts the root |
| Pending deduction | An approved payment that hasn't left the bank yet |
| Resolve | Marking a pending deduction as actually paid |
| Intra-flow / Fund transfer / Category fund transfer | Moving money between funds or pockets — nothing enters or leaves |
| Bulk reallocation | Many fund transfers done in one go |
| FX / Foreign currency | Money in another currency, like dollars or pounds |
| Conversion | Exchanging foreign money into your everyday currency |
| Exchange rate | How much of your currency one unit of foreign money is worth |
| Receipt | A photo or PDF proving a payment happened |
| Export / CSV | Downloading data as a spreadsheet file |
| Backup | A complete copy of all your data, saved as a file |
| Restore | Loading a backup file back into the app |
| Merge (restore) | Adding backup records next to current ones — safe |
| Replace (restore) | Wiping current data first, then loading the backup — dangerous |
| Role | What a user is allowed to do: Owner, Admin, Accountant, or Viewer |
| Owner | The one person with full control of the organisation |
| Admin | Can do almost everything except transfer ownership |
| Accountant | Can import and edit transactions, but not manage setup or people |
| Viewer | Can only look, not touch |
| Invite | A link that lets a new person join your organisation |
| 2FA / MFA | Two-step security: password PLUS a code from your phone |
| Authenticator app | The phone app that makes 2FA codes (Google Authenticator, Authy…) |
| Audit log / Activity History | The app's diary of every change anyone made |
| Accounting year | The year you are working in — pages and reports follow it |
| Dashboard | The home page with the big summary numbers |
| Template | A saved layout you can reuse, for reports or imports |
| Snapshot | Numbers frozen at a moment in time inside a custom report |
| Toast | The small message that pops up at the corner of the screen |
| Duplicate | The same transaction appearing twice — the import checker catches these |
