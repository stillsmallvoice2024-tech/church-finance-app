## What is the Receipts page?

Receipts are proof of payment — photos or PDF files of invoices and payment slips. This page is one big folder where every uploaded receipt lives. Find it at **Daily Finance → Receipts**.

## What's on the page

- **Folders** on the left (or as buttons on a phone): **All Receipts**, **Outflow Receipts**, **Inflow Receipts**, and **Bank Deposit Receipts**, each with a count.
- A search box and sort options.
- A grid of file cards. Each card shows the file name, the upload date, the file size, and what kind of record it belongs to.

## How to attach a receipt to a transaction

Receipts are attached from the transaction itself:

1. Go to the **Outflows** page (or Inflows) and find the transaction.
2. Click the row's expand arrow or the **pencil** to open it.
3. Use the receipt/attachment area to upload your photo or PDF.
4. The file then appears here on the Receipts page automatically, and the transaction row shows a paper-clip.

## How to find and download a receipt

1. Open the Receipts page.
2. Click the folder you want (for example **Outflow Receipts**).
3. Type part of the file name in the search box.
4. Move your mouse over the file card and click the blue **download** button. The file saves to your device.

## How to delete a receipt

1. Find the file card.
2. Hover over it and click the red **trash** button.
3. Confirm. Careful — the file is gone for good (the transaction itself is not deleted).

## If something goes wrong

- **"No receipts in this folder yet."** — nothing has been uploaded for that kind of record.
- **A red box with technical text appears** — the receipts storage hasn't been set up yet. Show the message to your administrator; it contains the exact instructions they need.
- **You can't find a receipt** — check a different folder, or clear the search box.
